# Sl-collection-
Loja virtual da SL COLLECTION, especializada em moda feminina, alfaiataria, shorts e conjuntos. Um e-commerce moderno e sofisticado, com identidade visual em rosa blush, off-white, bege e dourado. Desenvolvido com React e Vite, com catálogo de produtos, sacola de compras e atendimento via WhatsApp. Seu estilo, sua essência. 🌷
